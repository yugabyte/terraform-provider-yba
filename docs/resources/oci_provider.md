# yba_oci_provider (Resource)

OCI Cloud Provider Resource. Use this resource to create and manage Oracle Cloud Infrastructure providers in YugabyteDB Anywhere.

~> **Note:** This resource requires YugabyteDB Anywhere 2026.1.2.0 or later. `terraform plan` fails on an older YBA.

## Credentials

API-key authentication is the default. Set `tenancy_id`, `user_id`, `fingerprint`, and exactly one of `private_key_content` or `private_key_file_path`. An explicit `use_instance_principal = false` is the same mode and is set together with those fields. The file is read when an apply creates the provider or updates any auth field. Overwriting the file without changing the path or another auth field does not plan an update. A leading `~` is expanded to the home directory.

Set `use_instance_principal = true` to authenticate as the instance principal of the YugabyteDB Anywhere host, and omit the API-key fields. The provider rejects the API-key fields only when that value is true.

`compartment_id`, `tenancy_id`, `user_id`, `fingerprint`, `hosted_zone_id`, and `use_instance_principal` cannot be changed while a universe uses the provider. YugabyteDB Anywhere rejects the edit. `default_region` and the API private key can be changed.

`private_key_content` and `ssh_private_key_content` are stored in Terraform state. Changing `private_key_content` updates the provider in place.

## Example Usage

```terraform
# API-key authentication. An explicit false is valid next to the API-key fields.
# The private key is read from a file at apply time.
resource "yba_oci_provider" "example" {
  name           = "oci-provider"
  compartment_id = "ocid1.compartment.oc1..aaaa"
  default_region = "us-ashburn-1"

  use_instance_principal = false
  tenancy_id             = "ocid1.tenancy.oc1..aaaa"
  user_id                = "ocid1.user.oc1..aaaa"
  fingerprint            = "12:34:56:78:90:ab:cd:ef"
  private_key_file_path  = "~/.oci/oci_api_key.pem"

  hosted_zone_id = "ocid1.dns-zone.oc1..aaaa"

  air_gap_install = false
  set_up_chrony   = true
  ntp_servers     = ["169.254.169.123"]

  ssh_keypair_name        = "my-key"
  ssh_private_key_content = file("~/.ssh/my-key.pem")

  regions {
    code                      = "us-ashburn-1"
    vcn_id                    = "ocid1.vcn.oc1.iad.aaaa"
    instance_configuration_id = "ocid1.instanceconfiguration.oc1.iad.aaaa"
    zones {
      code   = "us-ashburn-1-AD-1"
      subnet = "ocid1.subnet.oc1.iad.aaaa"
    }
  }

  yba_managed_image_bundles {
    arch           = "x86_64"
    use_as_default = true
  }

  image_bundles {
    name           = "custom-alma9"
    use_as_default = false
    details {
      arch     = "x86_64"
      ssh_user = "opc"
      ssh_port = 22
      region_overrides = {
        "us-ashburn-1" = "ocid1.image.oc1.iad.aaaa"
      }
    }
  }
}

# Instance principal of the YugabyteDB Anywhere host.
# The API-key fields are omitted because use_instance_principal is true.
resource "yba_oci_provider" "instance_principal" {
  name                   = "oci-instance-principal"
  compartment_id         = "ocid1.compartment.oc1..aaaa"
  default_region         = "us-ashburn-1"
  use_instance_principal = true

  regions {
    code   = "us-ashburn-1"
    vcn_id = "ocid1.vcn.oc1.iad.aaaa"
    zones {
      code   = "us-ashburn-1-AD-1"
      subnet = "ocid1.subnet.oc1.iad.aaaa"
    }
  }

  yba_managed_image_bundles {
    arch = "x86_64"
  }
}

# API-key authentication with the PEM in configuration.
resource "yba_oci_provider" "private_key" {
  name           = "oci-provider-key"
  compartment_id = "ocid1.compartment.oc1..aaaa"
  default_region = "us-ashburn-1"

  use_instance_principal = false
  tenancy_id             = "ocid1.tenancy.oc1..aaaa"
  user_id                = "ocid1.user.oc1..aaaa"
  fingerprint            = "12:34:56:78:90:ab:cd:ef"
  private_key_content    = file("~/.oci/oci_api_key.pem")

  regions {
    code   = "us-ashburn-1"
    vcn_id = "ocid1.vcn.oc1.iad.aaaa"
    zones {
      code   = "us-ashburn-1-AD-1"
      subnet = "ocid1.subnet.oc1.iad.aaaa"
    }
  }

  yba_managed_image_bundles {
    arch           = "aarch64"
    use_as_default = false
  }
}
```

## Schema

### Required

- `compartment_id` (String) OCID of the OCI compartment YugabyteDB Anywhere uses for this provider. YugabyteDB Anywhere rejects changes to this field while a universe uses the provider.
- `default_region` (String) Default OCI region for the provider, for example `us-ashburn-1`.
- `name` (String) Name of the provider.
- `regions` (Block List, Min: 1) OCI regions associated with the provider. (see [below for nested schema](#nestedblock--regions))

### Optional

- `air_gap_install` (Boolean) Flag indicating if YugabyteDB nodes are installed in an air-gapped environment, lacking access to the public internet for package downloads. Default is false.
- `fingerprint` (String) Fingerprint of the API public key. YugabyteDB Anywhere returns it unmasked. Required for API-key authentication. Omit it when `use_instance_principal` is true. YugabyteDB Anywhere rejects changes to this field while a universe uses the provider.
- `hosted_zone_id` (String) OCID of the OCI DNS zone used as the hosted zone. YugabyteDB Anywhere rejects changes to this field while a universe uses the provider.
- `image_bundles` (Block List) Custom image bundles for the OCI provider. At least one image_bundles or yba_managed_image_bundles block must be specified. Every bundle must supply a non-empty image OCID in region_overrides for each configured region. (see [below for nested schema](#nestedblock--image_bundles))
- `ntp_servers` (List of String) List of NTP servers for time synchronization.
- `private_key_content` (String, Sensitive) OCI API private key in PEM form. Set exactly one of `private_key_content` or `private_key_file_path` for API-key authentication, including when `use_instance_principal` is explicitly false. Omit both when `use_instance_principal` is true. YugabyteDB Anywhere masks this on every provider response, so Terraform keeps the configured value. Changing it updates the provider in place.

~> **Security Note:** This value is stored in Terraform state. Use an encrypted backend.

- `private_key_file_path` (String) Path of an OCI API private key PEM file. The provider reads the file when the plan is applied and sends the contents as the API key. A leading `~` is expanded to the home directory. Set exactly one of `private_key_content` or `private_key_file_path` for API-key authentication, including when `use_instance_principal` is explicitly false. Omit both when `use_instance_principal` is true. The path is not sent to YugabyteDB Anywhere and is not read back. Overwriting the file at the same path plans an update only when another auth field changes in that apply, because Terraform diffs the path and not the file body. To rotate the key by itself, change the path or set `private_key_content`, after removing the key argument from any `lifecycle.ignore_changes`.
- `set_up_chrony` (Boolean) Set up NTP chrony service. When true with empty ntp_servers, uses cloud provider's NTP server (e.g., AWS Time Sync). When true with ntp_servers specified, uses custom NTP servers. When false, assumes NTP is pre-configured in the machine image. Default is false.
- `ssh_keypair_name` (String) Custom SSH key pair name to access YugabyteDB nodes. Must be set together with ssh_private_key_content. If both are omitted, YugabyteDB Anywhere generates and manages the key pair. YBA versions keys on every update: if a key with this name already exists it appends a timestamp. Use access_key_code to read the versioned name that was stored. This value is not read back.
- `ssh_private_key_content` (String, Sensitive) SSH private key content to access YugabyteDB nodes. Must be set together with ssh_keypair_name. If both are omitted, YugabyteDB Anywhere generates and manages the key pair. This value is not read back.

~> **Security Note:** This value is stored in Terraform state. Use an encrypted backend.

- `tenancy_id` (String) OCID of the OCI tenancy. Required for API-key authentication. Omit it when `use_instance_principal` is true. YugabyteDB Anywhere rejects changes to this field while a universe uses the provider.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `use_instance_principal` (Boolean) Authenticate as the instance principal of the YugabyteDB Anywhere host when true. An explicit false is API-key authentication and is set together with `tenancy_id`, `user_id`, `fingerprint`, and exactly one of `private_key_content` or `private_key_file_path`. Omit those fields when this is true. Default is false, which sends API_KEY authentication. YugabyteDB Anywhere rejects changes to this field while a universe uses the provider.
- `user_id` (String) OCID of the OCI user whose API key YugabyteDB Anywhere uses. Required for API-key authentication. Omit it when `use_instance_principal` is true. YugabyteDB Anywhere rejects changes to this field while a universe uses the provider.
- `yba_managed_image_bundles` (Block List, Max: 2) YBA managed image bundles for the provider. At least one image_bundles or yba_managed_image_bundles block must be specified. OCI supports up to two entries: one for x86_64 and one for aarch64. Omit this block to stop managing YBA default images via Terraform (any previously tracked bundles will be removed from the provider on the next apply). (see [below for nested schema](#nestedblock--yba_managed_image_bundles))

## Import

OCI providers can be imported using the provider UUID:

```sh
terraform import yba_oci_provider.example <provider-uuid>
```

An instance-principal provider plans cleanly after import.

YugabyteDB Anywhere masks the API private key in every provider response and never receives `private_key_file_path`, so an imported API-key provider has neither argument in state. To keep the plan empty, add the argument your configuration sets (`private_key_content` or `private_key_file_path`) to `lifecycle.ignore_changes`. Remove it from `ignore_changes` before you rotate the key: while it is ignored, a key change plans nothing.

`ssh_keypair_name` and `ssh_private_key_content` are not read back either, because YugabyteDB Anywhere renames the key pair when it rotates it. For a provider with a custom SSH key, add both to `lifecycle.ignore_changes` as well. Without that, the first apply after the import uploads the configured SSH key again.
