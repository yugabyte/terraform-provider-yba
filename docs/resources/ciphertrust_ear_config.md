# yba_ciphertrust_ear_config (Resource)

Manages a YugabyteDB Anywhere encryption-at-rest configuration that uses an AES key in Thales CipherTrust Manager as the master key. YugabyteDB Anywhere uses the key to wrap and unwrap the universe keys of each universe that uses the configuration.

~> **Note:** Requires YugabyteDB Anywhere 2025.1.0.0 or later, with the global runtime config key `yb.kms.allow_ciphertrust` set to `true`, for example with the `yba_runtime_config` resource. `terraform plan` fails on an older YBA, and an apply fails while the key is `false`.

Point the configuration at an existing key with `key_name`, or let YugabyteDB Anywhere create an AES key of `key_size` bits with that name. Terraform does not manage or delete a key that YugabyteDB Anywhere creates. An existing key must be an active AES key whose usage mask allows encrypt and decrypt.

There are two authentication modes, set by `auth_type`. With `PASSWORD`, YugabyteDB Anywhere logs in with `username` and `password`. With `REFRESH_TOKEN`, it uses `refresh_token`, a refresh token of a CipherTrust Manager user. The user must be able to read the key and to encrypt and decrypt with it, and to create keys when YugabyteDB Anywhere creates the key.

~> **Security Note:** `password` and `refresh_token` are stored in the Terraform state file and marked sensitive. Use a secure state backend and restrict access to state files.

~> **Note:** Only the arguments whose description says so can change in place. A change to any other argument forces replacement. YugabyteDB Anywhere does not delete a configuration that a universe has used: it keeps the universe's key history, also after encryption is disabled or the universe moves to another configuration, until the universe is deleted. A destroy of such a configuration fails, and the error names the universes. To move universes to a new configuration, create it, change `encryption_at_rest.kms_config_uuid` on each universe, and keep the old configuration (or remove it from state) until its universes are deleted. Give the new configuration `depends_on` on the old one, so that `terraform destroy` deletes the universe before the old configuration.

~> **Note:** Terraform refreshes `in_use` and the non-secret settings. YugabyteDB Anywhere masks credentials, so a credential changed outside Terraform, for example in the YugabyteDB Anywhere UI, does not show as drift. An apply sends a credential again only when the credential or the authentication mode changes.

Use the configuration in a universe through its `encryption_at_rest` block. The
[Encryption at Rest](../guides/universe-edit-actions.md#encryption-at-rest) section of the
Universe Edit Actions guide describes how to enable encryption, rotate the master key or the
universe key, and disable encryption. For the YugabyteDB Anywhere side, see
[Create a KMS configuration using CipherTrust](https://docs.yugabyte.com/stable/yugabyte-platform/security/create-kms-config/ciphertrust-kms/).

## Example Usage

```terraform
# Encryption-at-rest configuration on an existing AES key in CipherTrust
# Manager, with a user name and password for authentication. CipherTrust KMS
# must be allowed in YugabyteDB Anywhere, on the global scope.
resource "yba_runtime_config" "allow_ciphertrust" {
  key   = "yb.kms.allow_ciphertrust"
  value = "true"
}

resource "yba_ciphertrust_ear_config" "password" {
  name        = "ciphertrust-prod"
  manager_url = "https://ciphertrust.example.com"
  auth_type   = "PASSWORD"
  username    = "yba-kms"
  password    = var.ciphertrust_password
  key_name    = "yb-master-key"

  depends_on = [yba_runtime_config.allow_ciphertrust]
}

# Authentication with a refresh token. When the key does not exist,
# YugabyteDB Anywhere creates it as an AES key of key_size bits.
resource "yba_ciphertrust_ear_config" "refresh_token" {
  name          = "ciphertrust-central"
  manager_url   = "https://ciphertrust.example.com"
  auth_type     = "REFRESH_TOKEN"
  refresh_token = var.ciphertrust_refresh_token
  key_name      = "yb-central-key"
  key_size      = 128

  depends_on = [yba_runtime_config.allow_ciphertrust]
}

# A universe uses a configuration through its encryption_at_rest block:
#
#   encryption_at_rest {
#     enabled         = true
#     kms_config_uuid = yba_ciphertrust_ear_config.password.uuid
#   }
#
# The yba_universe example shows a complete universe with the block.
```

## Schema

### Required

- `key_name` (String) Name of the key in CipherTrust Manager. This key is the master key. YugabyteDB Anywhere creates it as an AES key of `key_size` bits when it does not exist. A change forces replacement.
- `manager_url` (String) URL of the CipherTrust Manager, for example `https://ciphertrust.example.com`. YugabyteDB Anywhere connects to it directly. A change forces replacement.
- `name` (String) Name of the configuration. Must be unique per customer. YugabyteDB Anywhere cannot rename a configuration, so a change forces replacement.

### Optional

- `auth_type` (String) How YugabyteDB Anywhere authenticates: `PASSWORD` or `REFRESH_TOKEN`. Defaults to `PASSWORD`. Can change in place, together with the credentials of the new type.
- `key_size` (Number) Size in bits of the AES key that YugabyteDB Anywhere creates: `128`, `192` or `256`, and `256` when not set. For an existing key, YugabyteDB Anywhere records the key's actual size, so leave this unset or set it to that size. A change forces replacement.
- `password` (String, Sensitive) Password of `username`. Required when `auth_type = "PASSWORD"`, and not allowed otherwise. Can change in place: YugabyteDB Anywhere first checks that the new credentials can decrypt the active universe key of each universe that uses the configuration.
- `refresh_token` (String, Sensitive) Refresh token of a CipherTrust Manager user. Required when `auth_type = "REFRESH_TOKEN"`, and not allowed otherwise. Can change in place.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `username` (String) CipherTrust Manager user name. Required when `auth_type = "PASSWORD"`, and not allowed otherwise. Can change in place.

### Read-Only

- `id` (String) The ID of this resource.
- `in_use` (Boolean) Whether a universe holds key history for this configuration. A configuration in use cannot be deleted.
- `uuid` (String) UUID of the configuration.

## Import

Import a CipherTrust configuration with its UUID. The `yba_ear_config` data source returns the
UUID for a configuration name:

```sh
terraform import yba_ciphertrust_ear_config.password <config-uuid>
```

Import fails for a configuration of another KMS provider, and the error names that provider.
Import reads every argument except `password` and `refresh_token`. YugabyteDB Anywhere masks
them when it lists a configuration, so import leaves them empty. When the configuration sets
`password` or `refresh_token`, the first plan after the import shows one in-place update, and
the apply sends the credential from your configuration.
